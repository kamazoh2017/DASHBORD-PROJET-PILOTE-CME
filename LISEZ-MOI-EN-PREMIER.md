## ⚡ Démarrage ultra-rapide (5 minutes)

### Option 1️⃣ : Je veux juste déployer maintenant

1. **Allez sur [vercel.com/signup](https://vercel.com/signup)** → Créez un compte gratuit
2. **Cliquez "Add New" → "Project"** → Sélectionnez ce repository
3. **Configurez les variables d'environnement** :
   ```
   DATABASE_URL = votre_connexion_postgresql
   ABACUSAI_API_KEY = votre_cle_api
   ```
4. **Cliquez "Deploy"** → Attendez 2-3 minutes
5. ✅ **C'est en ligne !**

📖 Guide détaillé : [DEMARRAGE-RAPIDE.md](DEMARRAGE-RAPIDE.md)

## 🤔 FAQ rapide

### C'est quoi ce projet ?
Un tableau de bord web pour suivre en temps réel le projet pilote de digitalisation du Carnet Mère-Enfant dans 5 hôpitaux de Côte d'Ivoire.

### C'est gratuit ?
**Oui !** Le déploiement sur Vercel est gratuit et illimité pour ce type de projet.

### Combien de temps ça prend ?
**5 minutes** pour déployer si vous suivez [DEMARRAGE-RAPIDE.md](DEMARRAGE-RAPIDE.md)

### Je n'y connais rien en programmation, je peux quand même ?
**Oui !** Suivez simplement les étapes de [DEMARRAGE-RAPIDE.md](DEMARRAGE-RAPIDE.md), c'est expliqué pas-à-pas.

### J'ai un problème, où trouver de l'aide ?
1. Consultez [FAQ.md](FAQ.md) - votre problème y est peut-être
2. Ouvrez une issue GitHub avec les détails
